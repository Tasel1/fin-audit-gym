Fin-Audit-Gym

Воспроизводимый симулятор и Gymnasium-среда для обучения и стресс-тестирования автономных агентов финансового аудита.

Gymnasium-контракт
Стандартизированный протокол reset и step для повторяющихся эпизодов обучения с подкреплением (RL).
Двойная запись
Генератор сбалансированной главной книги по принципу Clean-World-First со скрытым причинным графом изменений.
Биективный арбитраж
Оптимальный матчер 1-к-1 на алгоритме Куна-Манкреса, исключающий спам-атаки и галлюцинации моделей.

От статических отчетов к интерактивной среде

01 // ОГРАНИЧЕНИЕ
Слабость текстовой генерации
  • Языковые модели не способны автономно проводить аудит в режиме прямого вывода текста («generate report»).
  • Без инструментов исследования и первичных документов модель генерирует правдоподобные галлюцинации.
  • Для выработки устойчивой дедукции необходим цикл взаимодействия: гипотеза → проверка документа → верифицированное заключение.
02 // АРХИТЕКТУРА
Среда взаимодействия
  • Исследовательские действия: Модель постранично изучает журнал проводок, запрашивает инвойсы и банковские выписки через узкий API.
  • Математическая оценка: Терминальная награда вычисляется исключительно на основе доказанных фактов и приложенных ID документов.
  • Обучающие траектории: Фиксация чистых переходов State-Action-Reward для дообучения моделей через PPO или SFT.

Gymnasium API и изоляция данных

01 // API КОНТРАКТ
Протокол взаимодействия
Интерфейс в стандарте Gymnasium:
reset(seed, config) -> (obs, info) step(action) -> (obs, r, term, trunc, info)
Лимит 100 шагов на эпизод. Курсорная пагинация до 50 записей для работы в рамках контекстного окна модели.
02 // БЕЗОПАСНОСТЬ
AST-калькулятор
Исключение исполнения произвольного кода (RCE):
ast.parse(expr, mode='eval') Whitelist: BinOp, UnaryOp, Decimal
Отказ от eval() и импортов. Неверный ввод расходует шаг и возвращает контролируемую ошибку.
03 // ИЗОЛЯЦИЯ
Нулевая утечка (Zero-Leak)
Файлы truth.json и provenance.json хранятся вне процесса агента:
  • В пространстве наблюдений отсутствуют скрытые подсказки.
  • Seed эпизода агенту недоступен.
  • Изоляция подтверждена автоматическим интеграционным тестом.

Синтетический учет и инварианты баланса

01 // БАЛАНС
Принцип Clean-World-First
До внесения аномалий генератор строит сбалансированную историю двойной записи:
assert sum(debits) == sum(credits) Accounts: 1000 Cash, 1200 AR, 2000 AP, 4000 Rev, 5000 Exp, 7000 FX
  • Деньги — строго в целых минимальных единицах (копейки / центы) без погрешностей float.
  • FX-курсы валют — точные десятичные строки.
  • Отсутствующие связи — явные значения null.
02 // ТАКСОНОМИЯ
Аномалии и дистракторы
  • Duplicate Invoice: Повторные проводки счетов в главной книге.
  • Unallocated Payment: Пропущенное или частичное распределение платежа.
  • FX Mismatch: Ошибка даты или курса конвертации валюты.
  • Period Cutoff: Проводка операции за границей финансового года.
  • Составные сценарии: Частичный платеж в валюте на границе периода и круговые сделки.
  • Законные дистракторы: Разбитые платежи, возвраты и абонплаты.

Биективное сопоставление и функция награды

01 // МАТЧЕР
Алгоритм Куна-Манкреса (SciPy)
Оптимальное сопоставление 1-к-1 на двудольном графе:
from scipy.optimize import linear_sum_assignment row_ind, col_ind = linear_sum_assignment(cost_matrix)
  • Каждая реальная ошибка закрывается строго одним подтвержденным выводом.
  • Защита от спам-атак: Случайные обвинения или пометка всех строк подряд дают массу False Positives. Точность и F1 падают в 0, а награда опускается в -1.0.
02 // ФОРМУЛА
Терминальная функция награды
Формула оценки качества выводов:
Reward = clip(2 * F1 - 1 - 0.002 * inspection_steps, -1, 1)
  • Тест чистой книги: Тишина на чистых книгах дает максимальную награду (+0.998). Ложные тревоги наказываются падением до -1.0.
  • Нулевая награда за шаги: Промежуточная награда = 0, что устраняет зацикливание агента.

Инженерия и воспроизводимость

01 // ДАННЫЕ
Комплект поставки
  • Датасет: 10 обучающих и 10 тестовых эпизодов с закрытым эталоном.
  • trajectories.jsonl: 30 валидных траекторий взаимодействий без утечки ground-truth.
  • Dockerfile: Изолированное автономное окружение.
02 // ВЕРИФИКАЦИЯ
Единый запуск
Автоматическая проверка всего репозитория:
# Линтер + 60 тестов make check # Бенчмарк 4 политик python3 scripts/run_eval.py \ --data-dir data/dev --policy all
03 // ОГРАНИЧЕНИЯ
Границы моделирования
  • Программный симулятор сфокусирован на дедуктивной проверке фактов и не заменяет юридическое аудиторское заключение.
  • Сложность ориентирована на полноту доказательной базы, а не на неразрешимые парадоксы.
  • Проверена устойчивость к смене ID и перестановкам.

Стандартизация финансового ИИ

Fin-Audit-Gym готов занять нишу сертифицированного полигона для автономных ИИ-аудиторов перед их допуском к закрытым базам данных.

Big 4 & Аудит
Сертификация автономных агентов на соответствие международному аудиторскому стандарту ISA 500.
RL-Лаборатории
Среда для обучения reasoning-моделей дедуктивного анализа без риска спецификационного читерства.
FinTech Необанки
Стресс-тестирование форензик-ботов на синтетических данных перед интеграцией в боевую инфраструктуру.
